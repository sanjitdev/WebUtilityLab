- (constraint) Privacy Baseline (PRD FR-23): zero runtime network calls after page load; no analytics, no fonts, no CDN with request-body logging, no error reporters; audited transitive deps; open source day 1 — binds every AD
- (constraint) Static deploy only: output is dist/ files served by a CDN that does not log request bodies; no server runtime, no SSR, no edge functions touching the request body
- (constraint) 50 MB file cap (FR-1); UTF-8 with or without BOM; reads via FileReader / File.stream(); outputs via Blob URL + anchor download — no upload, no remote write
- (constraint) 10-second analysis budget (FR-6): pre-flight time-band shown while estimating; if upper-bound estimate exceeds 10s, advance to refusal state with no partial results
- (constraint) WCAG 2.2 AA + keyboard-first: skip-links, focus rings, aria-live regions, semantic HTML, no spinners (static 'Working…' text), prefers-reduced-motion respected (only motion is 180ms theme transition)
- (constraint) Cleaning defaults ALL OFF (FR-5); modal opens with reversibility view (original vs proposed diff); Confirm disabled until at least one toggle on; Cancel is initial focus
- (decision) AD-1 [ADOPTED]: stack = Vite + Svelte 5 + TypeScript; Binds the build toolchain, the reactive primitive (runes), and the TS compiler; Prevents drifting to React (bundle cost), Astro (overhead without payoff here), or vanilla TS (DOM ergonomics at scale) — alternative Preact kept as coin-flip second if React-shaped code is preferred
- (decision) AD-2 [ADOPTED]: CSV parsing is streaming, character-by-character, byte-aware UTF-8 decoder; reads via File.stream() not FileReader.readAsText; Binds parser interface (incremental token stream: row, field, quote, escape, BOM, EOF); Prevents loading whole file into memory and prevents readAsText (mangles BOM)
- (decision) AD-3 [ADOPTED]: analysis runs in a dedicated Web Worker; UI thread is reserved for the static 'Working…' announcement, the pre-flight time-band, and the refusal timer; Binds the worker boundary (postMessage contract: {phase, progress, partial, refusal, results}); Prevents blocking the UI thread on parsing or detection
- (decision) AD-4 [ADOPTED]: detection is two-pass on parsed rows — pass 1 column-wise streaming stats (type inference, null density, distinct counts, casing variants, numeric min/max/mean/sigma, length min/max); pass 2 cross-row rules (duplicates by configurable key, outlier z-score on numeric columns, PII regex match, email/date format validity, inconsistent categorical grouping); Binds the two-pass contract; Prevents single-pass premature outlier calls and prevents per-row re-scanning
- (decision) AD-5 [ADOPTED]: state is a single immutable snapshot owned by the main thread; UI subscribes via Svelte 5 runes; transitions: empty -> active -> (processing|refusal) -> results -> (modal-open|results); Binds the state machine and the snapshot immutability; Prevents drift across components and prevents ad-hoc mutation
- (decision) AD-6 [ADOPTED]: cleaning is opt-in per category, default ALL OFF; toggles: dedupe, fill-missing, validate-and-flag, normalize-categorical, redact-PII; reversibility view required (original vs proposed diff) before Confirm enables; Binds the toggle set, the reversibility gate, and Confirm-disabled-until-anything-on; Prevents accidental data mutation and prevents irreversible flow without preview
- (decision) AD-7 [ADOPTED]: theme is a CSS-variable class flip on <html> (.dark); localStorage key wul-theme; first paint seeded by prefers-color-scheme; transition 180ms gated by prefers-reduced-motion; Binds the persistence key, the selector, and the motion gate; Prevents FOUC on reload and prevents unguarded motion
- (decision) AD-8 [ADOPTED]: visual tokens live in DESIGN.md and are referenced by token name (not hex) in component CSS; rule from UX spine: color reserved for semantic meaning (err / warn / pii / ok / accent), mono for data, sans for prose; Binds the token-only import rule; Prevents hex literals in components and prevents decorative color
